## The idea

Move has three main **views**. Each one turns the 32 pads into something different, so knowing where you are is half the battle.

- **Set Overview** is your shelf of songs. Each pad is a slot for one Set (up to 32). Move opens here when you switch it on, and a new Move comes with four **demo Sets**, ready to explore.
- **Note Mode** is your workbench for one track. The pads become drums or keys for that track's sound, so you can play, record and edit its notes. You will spend most of your time here.
- **Session Mode** is the bird's-eye view of a whole Set. The pads show every clip: each row of pads is one track, and each pad in a row is a slot for one of that track's clips. A column across the rows is a **scene**: a group of clips that can play together, such as a verse or a chorus.

You switch between Note Mode and Session Mode with the **Note/Session** button, just left of the track buttons. The Set Overview sits "above" both of them: you reach it with **Shift** and **Step 1**.

<Steps>
  <Step press="shift step-1" hold="shift" see="The pads show your Sets: lit pads are Sets and dark pads are empty slots.">
    Hold **Shift**, then press **Step 1**. This opens the Set Overview from anywhere.
    <Tip>Press **Shift** first and keep it down, then tap **Step 1**. If the pads already show your Sets, you are in the right place; go on to the next step.</Tip>
  </Step>
  <Step press="pads" see="The pad you pressed starts to pulse, showing that this Set is selected.">
    Press one of the **lit pads** to pick a Set. On a new Move, the lit pads are the demo Sets.
    <Tip>Avoid the dark pads for now. They are empty slots, and opening one would start a brand-new Set.</Tip>
  </Step>
  <Step press="play" hear="The selected Set plays.">
    Press **Play**. You can listen to a Set right here, before you even open it.
  </Step>
  <Step press="play" hear="The music stops.">
    Press **Play** again to stop.
  </Step>
  <Step press="tracks" see="The Set opens in Note Mode, and the pads turn into an instrument.">
    Press any **track button**. This opens the selected Set in Note Mode, ready to play that track.
  </Step>
  <Step press="note-session" see="A message on the display tells you the mode has changed, and the pads lit in colour are the Set's clips.">
    Press **Note/Session** to switch to Session Mode. Each lit pad is a clip. The dark pads are empty places where new clips could go.
    <Tip>Session Mode pads start and select clips instead of playing notes, so pressing a lit pad here may start that clip playing. Press **Play** to stop if it does.</Tip>
  </Step>
  <Step press="note-session" hold="note-session" see="Move shows Note Mode while you hold the button, and goes back to Session Mode when you let go.">
    Now **hold** **Note/Session** for a moment instead of tapping it. You get a quick peek at the other mode. Let go to return.
  </Step>
  <Step press="shift step-1" hold="shift" see="The Set Overview again, with your Set's pad pulsing.">
    Hold **Shift** and press **Step 1** to go back up to the Set Overview.
  </Step>
  <Step press="back" see="Move leaves the Set Overview and opens your Set again.">
    Press **Back**. This takes you back into the selected Set. It should reopen the mode you were in before, which here is Session Mode.
    <Tip>If you land in Note Mode instead, you're still inside the right Set. Press **Note/Session** to get to Session Mode.</Tip>
  </Step>
</Steps>

## Try it yourself

- In the Set Overview, press **Play**, then tap different lit pads one after another. You hear each Set in turn.
- In Session Mode, press **Play** and let the demo Set run. Now switch to Note Mode and back while it plays. Does the music stop, or carry on?
- Go to the Set Overview and open a different demo Set, this time with **Note/Session** instead of a track button. Which view does it open in?

## Good to know

- There are three ways out of the Set Overview: a **track button** opens the Set in Note Mode, **Note/Session** opens it in Session Mode, and **Back** takes you back into the Set.
- In Note Mode, holding a track button gives the same kind of quick peek at another track, as you saw in [Lesson 3](/first-moves/lessons/03-sets-tracks-clips/).
- You don't have to save before leaving a Set. Move saves it for you, including whenever you open the Set Overview.
